# 输入输出

## 常用程序框架

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 读取数据、计算、输出
    return 0;
}
```

关闭 C 与 C++ 流的同步后，统一使用 `cin/cout`。交互题需要及时输出时，要主动刷新，例如 `cout << flush`。

## `cin` 与 `getline`

- `cin >> s` 跳过前导空白，读到下一个空白为止。
- `getline(cin, s)` 读一整行，允许空格；读走行末换行，但不把换行写入字符串。
- 用 `>>` 读取数字后，输入流常留下换行。紧接着读下一行时，应按输入格式处理余下内容。

**要丢弃当前行剩余内容，读取下一行：**

```cpp
// 需要 <iostream>、<string>、<limits>；放在 main 内。
int n;
string line;
cin >> n;
cin.ignore(numeric_limits<streamsize>::max(), '\n');
getline(cin, line);
```

`cin.ignore()` 默认只丢弃一个字符。若数字后还有空格，仅调用一次可能没有丢掉换行。若正文就在数字同一行，也不能直接丢弃整行，要按题目格式读取。

**允许跳过所有前导空白：**

```cpp
// 需要 <iostream>、<string>；放在 main 内。
string line;
getline(cin >> ws, line);
```

`ws` 会跳过空行和行首空格。需要保留空行或缩进时，不要用这个写法。因此，“`cin` 后接 `getline` 必须写 `ignore()`”不是通用规则。

## 格式化输出

```cpp
// 需要 <iostream>、<iomanip>；放在 main 内。
cout << setfill('*') << setw(8) << 42 << '\n';  // ******42
cout << setfill(' ');                          // 恢复填充字符
cout << fixed << setprecision(2) << 3.14159 << '\n';  // 3.14
```

`setw` 设置下一次格式化输出的最小宽度；`setfill` 会持续生效。一般输出换行用 `'\n'`，`endl` 还会刷新缓冲区。
