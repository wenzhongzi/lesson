# 栈与队列

## 栈：后进先出

需要 `<stack>`。适用于括号匹配、回溯状态、单调栈等。

| 操作 | 含义 |
| --- | --- |
| `st.push(x)` | 入栈 |
| `st.top()` | 读取栈顶，不删除 |
| `st.pop()` | 删除栈顶，无返回值 |
| `st.empty()` | 判断是否为空 |
| `st.size()` | 获取元素个数 |

```cpp
// 需要 <stack>；放在 main 内。
stack<int> st;
st.push(10);
st.push(20);
if (!st.empty()) {
    int x = st.top();  // 20
    st.pop();
    (void)x;
}
```

## 队列：先进先出

需要 `<queue>`。适用于 BFS 和按进入顺序处理任务。

| 操作 | 含义 |
| --- | --- |
| `q.push(x)` | 队尾入队 |
| `q.front()` | 读取队首 |
| `q.back()` | 读取队尾 |
| `q.pop()` | 删除队首，无返回值 |
| `q.empty()` / `q.size()` | 判空 / 大小 |

```cpp
// 需要 <queue>；放在 main 内。
queue<int> q;
q.push(10);
q.push(20);
if (!q.empty()) {
    int x = q.front();  // 10
    q.pop();
    (void)x;
}
```

调用 `top/front/back/pop` 前应保证容器非空。单调队列需要同时删除两端元素，使用 `<deque>` 中的 `deque`，见[单调栈与单调队列](04-单调栈与单调队列.md)。
