# 哈希表

合并原笔记的 `hash` 与“数据结构 / 哈希”。

## `unordered_map`：键值映射

需要 `<unordered_map>`，字符串键另需 `<string>`。

```cpp
// 操作示例；放在 main 内。
unordered_map<int, int> mp;
mp[1] = 10;
mp[3]++;                 // 不存在则插入值 0，再递增
mp[3]++;                 // mp[3] == 2

if (mp.count(3)) { /* 键 3 存在 */ }
auto it = mp.find(99);
if (it != mp.end()) {
    int value = it->second;  // 查询时不插入新键
    (void)value;
}

mp.insert({1, 100});      // 键已存在，不覆盖原来的 10
mp[1] = 100;             // 需要覆盖时直接赋值
for (const auto& [key, value] : mp) {
    (void)key;
    (void)value;
}
mp.erase(1);
auto count = mp.size();
mp.clear();
(void)count;
```

频率统计常用 `mp[x]++`。仅判断是否存在时用 `count/find`，因为 `mp[x]` 会在键不存在时插入一个新元素。遍历顺序不保证按键排序，也不保证按插入顺序。

## 嵌套映射

```cpp
// 需要 <unordered_map>；放在 main 内。
unordered_map<int, unordered_map<int, long long>> cabinet;
cabinet[2][5] = 100;  // 第 2 个柜子的第 5 个格子
```

读取 `cabinet[x][y]` 也可能创建外层和内层记录。希望只查询时，需要分别对两层使用 `find`。

## `unordered_set`：去重与存在性

需要 `<unordered_set>`。

```cpp
// 放在 main 内。
unordered_set<int> st;
st.insert(5);
st.insert(2);
st.insert(5);           // 重复插入不增加元素；size() == 2
bool exists = st.count(2) != 0;
for (int x : st) { (void)x; }
st.erase(5);
st.clear();
(void)exists;
```

普通插入、查询、删除平均时间为 `O(1)`，最坏可以退化到 `O(n)`。需要有序遍历时考虑 `map/set`；键是较小范围的整数时，数组通常更直接。
