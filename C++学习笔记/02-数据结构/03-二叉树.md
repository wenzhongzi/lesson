# 二叉树

每个节点最多有两个孩子，分别称为左孩子和右孩子。普通二叉树不一定满足二叉搜索树的大小关系。

## 节点与建树

```cpp
struct TreeNode {
    int val;
    TreeNode* left = nullptr;
    TreeNode* right = nullptr;
    explicit TreeNode(int x) : val(x) {}
};
```

先创建节点，再连接关系。这个小例子用局部对象避免手动管理 `new/delete`：

```cpp
// 接在 TreeNode 定义后；放在 main 内。
TreeNode n1(1), n2(2), n3(3), n4(4);
TreeNode* root = &n1;
root->left = &n2;
root->right = &n3;
n2.left = &n4;
```

结构为根 1、左孩子 2、右孩子 3，节点 2 的左孩子为 4。节点指针仅在对应对象还存在时有效；返回函数局部节点的指针会产生悬空指针。

## 遍历

```cpp
// 需要 <iostream>；依赖上面的 TreeNode 定义。
void preOrder(TreeNode* root) {
    if (root == nullptr) return;
    cout << root->val << ' ';  // 根
    preOrder(root->left);      // 左
    preOrder(root->right);     // 右
}
```

| 遍历 | 顺序 | 上例输出 |
| --- | --- | --- |
| 前序 | 根 → 左 → 右 | `1 2 4 3` |
| 中序 | 左 → 根 → 右 | `4 2 1 3` |
| 后序 | 左 → 右 → 根 | `4 2 3 1` |

中序、后序只需调整输出语句位置。遍历时间 `O(n)`，递归辅助空间 `O(h)`，其中 `h` 是树高；链状树深度很大时要考虑显式栈。
