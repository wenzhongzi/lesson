# 单调栈与单调队列

两者都通过删除不可能再成为答案的候选元素，避免重复扫描。通常存**下标**，才能同时比较数值和判断位置。

## 单调栈：右侧第一个严格更大的元素

扫描到 `a[i]` 时，栈中所有比它小且还没找到答案的位置，都可以确定答案为 `i`。弹出这些位置后，将 `i` 入栈一次。

```cpp
// 需要 <vector>、<stack>；返回 0 基下标，找不到为 -1。
vector<int> nextGreater(const vector<int>& a) {
    int n = static_cast<int>(a.size());
    vector<int> ans(n, -1);
    stack<int> st;
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && a[i] > a[st.top()]) {
            ans[st.top()] = i;
            st.pop();
        }
        st.push(i);
    }
    return ans;
}
```

例如 `[2, 1, 2, 4]` 的答案为 `[3, 2, 3, -1]`。题目要求从 1 编号且找不到输出 0 时，对非负答案加 1，对 `-1` 输出 0。

要找右侧第一个严格更小的元素，把比较改为 `<`。严格关系下，相等元素不能当作答案。原笔记中的 `empy()` 拼写、将值与下标比较、重复入栈均已修正。

每个下标入栈、出栈至多一次，时间 `O(n)`，空间 `O(n)`。

## 单调队列：长度为 `k` 的滑动窗口最大值

用 `deque` 保存候选下标，队首到队尾对应的数值严格递减；队首就是最大值。

处理顺序：删除过期下标 → 删除队尾劣势候选 → 当前下标入队 → 窗口完整时记录答案。

```cpp
// 需要 <vector>、<deque>；非法窗口大小返回空数组。
vector<int> windowMax(const vector<int>& a, int k) {
    int n = static_cast<int>(a.size());
    if (k <= 0 || k > n) return {};
    deque<int> q;
    vector<int> ans;
    for (int i = 0; i < n; ++i) {
        while (!q.empty() && q.front() <= i - k) q.pop_front();
        while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();
        q.push_back(i);
        if (i >= k - 1) ans.push_back(a[q.front()]);
    }
    return ans;
}
```

例：`[1, 3, -1, -3, 5, 3, 6, 7]`，`k = 3`，得到 `[3, 3, 5, 5, 6, 7]`。求最小值时把队尾比较改为 `>=`，形成递增队列。

相同值保留较新的位置，因为它更晚过期。总时间 `O(n)`，辅助空间 `O(k)`，不计输出。原练习线索：洛谷 P1886；[原始示意图](../assets/单调队列/滑动窗口最大值.png)。
