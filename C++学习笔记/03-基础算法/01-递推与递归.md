# 递推与递归

## 区别

| 方法 | 方向 | 重点 |
| --- | --- | --- |
| 递推 | 从已知小规模状态算出大规模状态 | 初值、关系式、计算顺序 |
| 递归 | 函数调用自身，把问题拆成较小问题 | 终止条件、规模缩小、返回结果 |

递归是一种实现方式，不等于动态规划；递推也不仅限于某一种算法。

## 斐波那契数列

统一定义 `F(0) = 0`、`F(1) = 1`，`F(n) = F(n-1) + F(n-2)`。例如 `F(5) = 5`。

```cpp
// 递推：要求 0 <= n <= 92，结果不超过 long long。
long long fibonacci(int n) {
    if (n == 0) return 0;
    long long prev = 0, cur = 1;
    for (int i = 2; i <= n; ++i) {
        long long next = prev + cur;
        prev = cur;
        cur = next;
    }
    return cur;
}
```

时间 `O(n)`，空间 `O(1)`。只求最后一项时不必保存整张数组。

```cpp
// 朴素递归：用于理解，不适合较大的 n。
long long fibonacciRecursive(int n) {
    if (n <= 1) return n;
    return fibonacciRecursive(n - 1) + fibonacciRecursive(n - 2);
}
```

计算 `F(5)` 会重复计算 `F(3)`、`F(2)` 等，时间为指数级，递归栈深度 `O(n)`。用记忆化缓存每个已算状态，可把时间降到 `O(n)`。

## 汉诺塔

三根柱子、每次移动一个盘子、小盘不能被大盘压住。将 `n` 个盘从 A 移到 C：先将上方 `n-1` 个移到 B，再移动最大盘，最后把 B 上的盘移到 C。

$$
H(0)=0,\qquad H(n)=2H(n-1)+1=2^n-1.
$$

```cpp
// 需要 <iostream>；要求 n >= 0。
void hanoi(int n, char from, char via, char to) {
    if (n == 0) return;
    hanoi(n - 1, from, to, via);
    cout << from << " -> " << to << '\n';
    hanoi(n - 1, via, from, to);
}
```

输出所有移动需 `O(2^n)` 时间。C++ 的 `^` 是按位异或，不是乘方；只求次数时按数值范围选择整数或高精度计算。
