# 排序

## 标准库排序

```cpp
// 需要 <algorithm>、<functional>、<vector>；放在 main 内。
vector<int> a = {3, 1, 2};
sort(a.begin(), a.end());                  // 升序
sort(a.begin(), a.end(), greater<int>());  // 降序
stable_sort(a.begin(), a.end());           // 保留相等元素的原相对顺序
```

普通数组 `a[0..n-1]` 使用 `sort(a, a+n)`。比较器必须表示严格顺序，不能用 `<=` 或 `>=`。

```cpp
// 需要 <algorithm>、<vector>；放在 main 内。
struct Item { int score, id; };
vector<Item> a = {{90, 2}, {90, 1}, {80, 3}};
sort(a.begin(), a.end(), [](const Item& x, const Item& y) {
    if (x.score != y.score) return x.score > y.score;
    return x.id < y.id;  // 同分时按 id 排序
});
```

需要“同关键字保持输入顺序”时使用 `stable_sort`，或者把原输入位置作为次关键字。标准规定稳定性和复杂度等行为，不要求 `stable_sort` 必须采用某一种具体实现。[Microsoft 标准库文档](https://learn.microsoft.com/en-us/cpp/standard-library/algorithm?view=msvc-170)。

## 常见算法对比

下表针对通常的数组实现；“稳定”表示相等关键字的原相对顺序保持不变。空间为额外辅助空间。

| 算法 | 最好时间 | 平均时间 | 最坏时间 | 空间 | 稳定 |
| --- | --- | --- | --- | --- | --- |
| 直接插入 | `O(n)` | `O(n²)` | `O(n²)` | `O(1)` | 是 |
| 二分插入 | `O(n log n)` 比较 | `O(n²)` 总时间 | `O(n²)` | `O(1)` | 是，插在相等值之后 |
| 直接选择 | `O(n²)` | `O(n²)` | `O(n²)` | `O(1)` | 否 |
| 优化冒泡 | `O(n)` | `O(n²)` | `O(n²)` | `O(1)` | 是 |
| 希尔 | 取决于增量序列 | 取决于增量序列 | 折半增量可达 `O(n²)` | `O(1)` | 否 |
| 快速 | `O(n log n)` | `O(n log n)` | `O(n²)` | 递归栈平均 `O(log n)`，最坏 `O(n)` | 否 |
| 堆 | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(1)`，迭代调整 | 否 |
| 二路归并 | `O(n log n)` | `O(n log n)` | `O(n log n)` | `O(n)` | 是，相等时先取左半 |

## 插入排序与二分插入

在已排序前缀中找到当前元素位置，把更大的元素右移，再插入。

```cpp
// 需要 <vector>。
void insertionSort(vector<int>& a) {
    for (int i = 1; i < static_cast<int>(a.size()); ++i) {
        int x = a[i], j = i - 1;
        while (j >= 0 && a[j] > x) {
            a[j + 1] = a[j];
            --j;
        }
        a[j + 1] = x;
    }
}
```

有序输入只需约 `n-1` 次关键字比较；逆序输入需要约 `n(n-1)/2` 次关键字比较和移动。二分插入减少找位置的比较次数，但移动元素仍可能需要 `O(n²)` 总时间。用 `upper_bound` 找插入点，才能把新元素放到相等元素之后。

## 选择排序

每轮在未排序部分找最小值，交换到该部分首位。比较次数固定为 `n(n-1)/2`；远距离交换可能改变相等元素顺序。

```cpp
// 需要 <algorithm>、<vector>。
void selectionSort(vector<int>& a) {
    int n = static_cast<int>(a.size());
    for (int i = 0; i + 1 < n; ++i) {
        int k = i;
        for (int j = i + 1; j < n; ++j)
            if (a[j] < a[k]) k = j;
        swap(a[i], a[k]);
    }
}
```

原图中的“树排序”指**树形选择排序 / 锦标赛排序**：叶子存元素，内部节点存两者中的胜者；取出根的最小值后，更新它所在叶子到根的路径。建树 `O(n)`，排序 `O(n log n)`，额外空间 `O(n)`。相等时按原下标决定胜者可保持稳定；它与二叉搜索树排序不是同一个概念。

## 冒泡排序

```cpp
// 需要 <algorithm>、<vector>。
void bubbleSort(vector<int>& a) {
    int n = static_cast<int>(a.size());
    for (int end = n - 1; end > 0; --end) {
        bool swapped = false;
        for (int j = 0; j < end; ++j) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}
```

每轮把最大值交换到未排序部分末尾。只有加入“本轮无交换则退出”，最好时间才是 `O(n)`。

## 快速排序

选基准 → 划分 → 递归处理两半。以下使用末元素作基准，划分后基准落到最终位置：

```cpp
// 需要 <algorithm>、<vector>；初次调用 quickSort(a, 0, int(a.size())-1)。
void quickSort(vector<int>& a, int left, int right) {
    if (left >= right) return;
    int pivot = a[right], p = left;
    for (int i = left; i < right; ++i) {
        if (a[i] < pivot) swap(a[i], a[p++]);
    }
    swap(a[p], a[right]);
    quickSort(a, left, p - 1);
    quickSort(a, p + 1, right);
}
```

这份教学模板在已排序、逆序或大量重复值时可能退化。实际做题一般直接使用 `sort`。随机基准可改善期望表现，大量重复值可考虑三路划分。

不同划分方案的指针规则不同；不能混用“交换后都移动”和“先扫描再交换”。上面是基准归位的方案，某些其他划分方案只保证分成两个区间，基准不一定归位。

## 堆排序、归并与希尔

- **堆排序**：升序排序使用大顶堆。自底向上建堆；把根与堆尾交换，缩小堆范围，然后让根向下调整，与较大的孩子比较，直到满足堆性质。建堆 `O(n)`，后续 `O(n log n)`。
- **归并排序**：递归排序左右两半，再用辅助数组合并。相等时先取左半元素，保证稳定。
- **希尔排序**：按增量 `gap` 将元素分组，对各组做插入排序，逐步减小增量，最后 `gap=1`。

```cpp
// 需要 <vector>；折半增量的希尔排序。
void shellSort(vector<int>& a) {
    int n = static_cast<int>(a.size());
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; ++i) {
            int x = a[i], j = i;
            while (j >= gap && a[j - gap] > x) {
                a[j] = a[j - gap];
                j -= gap;
            }
            a[j] = x;
        }
    }
}
```
