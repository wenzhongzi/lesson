# 二分答案

把“直接求最优答案”转为“给定候选答案 `x`，判断能否满足条件”。

## 使用条件

1. 确定答案所在区间。
2. `check(x)` 的真假随 `x` 单调变化，合法和不合法分成两段。
3. 确定求最大可行值还是最小可行值，再决定移动方向。

## 最小可行值

若小值不可行、大值可行，即 `false ... false true ... true`：

```cpp
// 需要 <optional>。check 是接收 long long、返回 bool 的函数或 lambda。
// L <= R，且 R-L、边界加减均在 long long 范围内。
template <class Check>
optional<long long> firstFeasible(long long L, long long R, Check check) {
    optional<long long> ans;
    while (L <= R) {
        long long mid = L + (R - L) / 2;
        if (check(mid)) {
            ans = mid;
            R = mid - 1;
        } else {
            L = mid + 1;
        }
    }
    return ans;
}
```

## 最大可行值

若小值可行、大值不可行，即 `true ... true false ... false`：

```cpp
// 需要 <optional>；范围条件与上一模板相同。
template <class Check>
optional<long long> lastFeasible(long long L, long long R, Check check) {
    optional<long long> ans;
    while (L <= R) {
        long long mid = L + (R - L) / 2;
        if (check(mid)) {
            ans = mid;
            L = mid + 1;
        } else {
            R = mid - 1;
        }
    }
    return ans;
}
```

返回空 `optional` 表示给定区间内无解，避免把初值 0 误当成合法答案。

## 示例：切绳子

给若干整数长度的绳子，切出至少 `k` 段同样长的绳子，求最大整数长度。候选长度 `x >= 1` 可行，当且仅当 `sum(length / x) >= k`；长度越大，可切段数越少，所以求最大可行值。

```cpp
// 需要 <algorithm>、<iostream>、<optional>、<vector>；
// 依赖 lastFeasible；放在 main 内。要求 k > 0、绳长非负。
vector<long long> ropes = {8, 7, 9};
long long k = 5;
auto check = [&](long long x) {
    long long count = 0;
    for (long long len : ropes) {
        long long pieces = len / x;
        if (pieces >= k - count) return true;  // 提前返回并避免累加溢出
        count += pieces;
    }
    return false;
};
long long upper = *max_element(ropes.begin(), ropes.end());
auto ans = lastFeasible(1, upper, check);
cout << ans.value_or(0) << '\n';  // 4；没有正长度方案则输出 0
```

复杂度 `O(T_check × log(答案范围))`。中点公式避免常见的 `L+R` 溢出，但 `R-L` 也必须能表示；不能把模板不加调整地用于完整的有符号整数范围。
