# 双指针与滑动窗口

双指针通过维护两个位置，利用单调移动避免重复扫描。常见形式是左右指针和同向滑动窗口。

## 固定长度窗口

先计算第一个窗口，之后每次删除左端旧元素、加入右端新元素。

```cpp
// 需要 <algorithm>、<optional>、<vector>；要求所有窗口和可用 long long 表示。
optional<long long> maxWindowSum(const vector<int>& a, int k) {
    int n = static_cast<int>(a.size());
    if (k <= 0 || k > n) return nullopt;
    long long sum = 0;
    for (int i = 0; i < k; ++i) sum += a[i];
    long long ans = sum;
    for (int r = k; r < n; ++r) {
        sum += static_cast<long long>(a[r]) - a[r - k];
        ans = max(ans, sum);
    }
    return ans;
}
```

时间 `O(n)`，辅助空间 `O(1)`。答案初始化为第一个窗口和，不能初始化为 0，否则全负数输入会出错。

## 可变长度窗口：和至少为 `target` 的最短连续子数组

**前提：数组元素非负，`target > 0`。** 右移右端会使和不减；左移左端会使和不增，满足单调性。

```cpp
// 需要 <algorithm>、<vector>；总和需能用 long long 表示；无解返回 0。
int minLengthAtLeast(const vector<int>& a, long long target) {
    int n = static_cast<int>(a.size()), left = 0, ans = n + 1;
    long long sum = 0;
    for (int right = 0; right < n; ++right) {
        sum += a[right];
        while (left <= right && sum >= target) {
            ans = min(ans, right - left + 1);
            sum -= a[left++];
        }
    }
    return ans == n + 1 ? 0 : ans;
}
```

例：`[2, 3, 1, 2, 4, 3]`，目标 7，最短长度为 2，对应 `[4, 3]`。

不同题目的收缩条件不同：求“至少某个和”的最短窗口时，在满足条件后更新答案再收缩；求“最多含若干种元素”的最长窗口时，应先收缩到合法，再更新答案。原文中的通用伪代码不能直接用于所有窗口题。

含负数时，区间和不再随窗口单调变化，以上可变窗口模板不适用。两个指针各移动至多 `n` 次，所以总时间 `O(n)`。
