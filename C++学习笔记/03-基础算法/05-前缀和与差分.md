# 前缀和与差分

前缀和适合“预处理后多次查询区间和”；差分适合“多次区间加，最后恢复数组”。本章统一从 **1** 开始编号，并保留第 0 行 / 列为 0。

## 一维前缀和

$$
s[0]=0,\quad s[i]=s[i-1]+a[i],\quad
\operatorname{sum}(l,r)=s[r]-s[l-1].
$$

```cpp
// 需要 <vector>；放在 main 内。a[0] 只是占位。
vector<long long> a = {0, 1, 2, 3, 4};
int n = static_cast<int>(a.size()) - 1;
vector<long long> s(n + 1, 0);
for (int i = 1; i <= n; ++i) s[i] = s[i - 1] + a[i];
int l = 2, r = 4;
long long rangeSum = s[r] - s[l - 1];  // 9
(void)rangeSum;
```

构造 `O(n)`，单次查询 `O(1)`。

## 一维差分

$$
d[i]=a[i]-a[i-1],\qquad a[i]=\sum_{j=1}^{i}d[j].
$$

对闭区间 `[l,r]` 加 `v`：`d[l] += v`，`d[r+1] -= v`。

```cpp
// 需要 <vector>；放在 main 内。
vector<long long> a = {0, 1, 2, 3, 4};
int n = static_cast<int>(a.size()) - 1;
vector<long long> d(n + 2, 0);
for (int i = 1; i <= n; ++i) d[i] = a[i] - a[i - 1];
int l = 2, r = 4;
long long v = 10;
d[l] += v;
d[r + 1] -= v;
for (int i = 1; i <= n; ++i) a[i] = a[i - 1] + d[i];
// a[1..4] 变为 1, 12, 13, 14
```

若题目要求每次修改后立即查询，普通差分通常不够，需要其他数据结构。

## 二维前缀和

`s[i][j]` 表示矩形 `[1..i] × [1..j]` 的**元素和**，不是几何面积。

$$
s[i][j]=a[i][j]+s[i-1][j]+s[i][j-1]-s[i-1][j-1].
$$

闭矩形左上角 `(x1,y1)`、右下角 `(x2,y2)`：

$$
\operatorname{sum}=s[x2][y2]-s[x1-1][y2]-s[x2][y1-1]+s[x1-1][y1-1].
$$

这里 `x` 是行号，`y` 是列号。预处理 `O(nm)`，查询 `O(1)`。原图采用另一种边界标记方式，使用时以本章统一坐标为准。

## 二维差分

初始数组不是全 0 时：

$$
d[i][j]=a[i][j]-a[i-1][j]-a[i][j-1]+a[i-1][j-1].
$$

对闭矩形加 `v`，在四个角更新，再求二维前缀和恢复。下面以 2×3 全零数组为例：

```cpp
// 需要 <vector>；放在 main 内。分配 n+2、m+2，保留边界外一格。
int n = 2, m = 3;
vector<vector<long long>> d(n + 2, vector<long long>(m + 2, 0));
int x1 = 1, y1 = 2, x2 = 2, y2 = 3;
long long v = 5;
d[x1][y1] += v;
d[x1][y2 + 1] -= v;
d[x2 + 1][y1] -= v;
d[x2 + 1][y2 + 1] += v;
for (int i = 1; i <= n; ++i)
    for (int j = 1; j <= m; ++j)
        d[i][j] += d[i - 1][j] + d[i][j - 1] - d[i - 1][j - 1];
// 恢复后的两行均为 0, 5, 5
```
