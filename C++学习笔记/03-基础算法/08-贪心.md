# 贪心

每一步选一个局部最优决策，并证明这个决策能包含在某个全局最优解中。仅凭直觉选最小或最大值，不足以保证正确。

## 区间题对照

| 目标 | 排序 | 每一步选择 |
| --- | --- | --- |
| 最多互不重叠区间 | 右端点升序 | 可选区间中最早结束者 |
| 最少点覆盖所有闭区间 | 右端点升序 | 尚未覆盖区间的右端点 |
| 最少区间覆盖 `[L,R]` | 左端点升序 | 起点可衔接且右端点最远者 |

以下三个函数需要 `<algorithm>`、`<vector>`，共用结构：

```cpp
struct Interval { long long l, r; };  // 要求 l <= r
```

## 最多互不重叠区间

```cpp
// 按闭区间处理，端点相同也算重叠。
int maxDisjoint(vector<Interval> seg) {
    sort(seg.begin(), seg.end(), [](const Interval& a, const Interval& b) {
        return a.r < b.r;
    });
    bool chosen = false;
    long long last = 0;
    int count = 0;
    for (const auto& s : seg) {
        if (!chosen || s.l > last) {
            ++count;
            last = s.r;
            chosen = true;
        }
    }
    return count;
}
```

若是活动安排，结束时间等于下一场开始时间允许衔接，则把 `s.l > last` 改为 `s.l >= last`。原文“右端点降序”已修正。

证明要点：把最优解中最先结束的区间换成全体可选区间中最早结束者，不会减少后续选择空间。重复这个过程即可。

## 最少选点

```cpp
int minPoints(vector<Interval> seg) {
    sort(seg.begin(), seg.end(), [](const Interval& a, const Interval& b) {
        return a.r < b.r;
    });
    bool chosen = false;
    long long last = 0;
    int count = 0;
    for (const auto& s : seg) {
        if (!chosen || s.l > last) {
            ++count;
            last = s.r;
            chosen = true;
        }
    }
    return count;
}
```

与上一个模板形似，但含义不同：`last` 是已经放置的点。闭区间满足 `l <= last <= r` 就已覆盖。空输入返回 0，不能未经判断就访问第一个区间或把答案初始化为 1。

## 最少区间覆盖整段

```cpp
// 连续实数线段覆盖；相邻端点允许相接；无法覆盖返回 -1。
int minCover(vector<Interval> seg, long long L, long long R) {
    if (L > R) return -1;
    if (L == R) {
        for (const auto& s : seg)
            if (s.l <= L && L <= s.r) return 1;
        return -1;
    }
    sort(seg.begin(), seg.end(), [](const Interval& a, const Interval& b) {
        return a.l < b.l;
    });
    int i = 0, count = 0, n = static_cast<int>(seg.size());
    long long cur = L;
    while (cur < R) {
        long long farthest = cur;
        while (i < n && seg[i].l <= cur) {
            farthest = max(farthest, seg[i].r);
            ++i;
        }
        if (farthest == cur) return -1;
        cur = farthest;
        ++count;
    }
    return count;
}
```

已经扫描且没选中的区间，其右端点不会超过本轮最远点，之后也无法帮助继续延伸。上述区间算法总时间 `O(n log n)`，排序后扫描 `O(n)`。

## 排队接水：最小总等待时间

每个人接水时间为 `t[i]`，一台水龙头。按接水时间从小到大排列。

```cpp
// 需要 <algorithm>、<vector>；等待时间总和可用 long long 表示。
long long totalWaiting(vector<long long> t) {
    sort(t.begin(), t.end());
    long long elapsed = 0, waiting = 0;
    for (long long x : t) {
        waiting += elapsed;
        elapsed += x;
    }
    return waiting;
}
```

交换相邻且耗时逆序的两个人，只会减少其中后一人的等待时间，不影响后面所有人的开始时刻。若题目问平均等待时间，再用浮点数除以人数，人数为 0 时单独处理。
