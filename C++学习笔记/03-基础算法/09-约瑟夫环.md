# 约瑟夫环

有 `n` 个人，编号 `1..n`，从编号 1 开始报数，数到 `m` 的人出局，下一人从 1 继续报数。要求 `n >= 1`、`m >= 1`。

必须区分**当前剩余序列中的下标**与**最初编号**。

## 输出全部出局编号

```cpp
// 需要 <numeric>、<vector>；简单模拟，适合较小 n。
vector<int> eliminationOrder(int n, long long m) {
    vector<int> people(n);
    iota(people.begin(), people.end(), 1);
    vector<int> result;
    long long pos = 0;
    while (!people.empty()) {
        long long size = static_cast<long long>(people.size());
        pos = (pos + (m - 1) % size) % size;
        result.push_back(people[static_cast<size_t>(pos)]);
        people.erase(people.begin() + static_cast<int>(pos));
        // 删除后该下标指向下一个人；到末尾时，下一轮取模会回到开头。
    }
    return result;
}
```

核心位置公式是 `(pos + m - 1) % 当前人数`，但它得到的是**位置**。必须查询 `people[pos]` 才能得到原编号。原笔记直接输出 `pos+1` 的写法已修正。

例：`n=5, m=2`，出局顺序为 `2 4 1 5 3`。由于 `vector::erase` 要移动元素，总时间 `O(n²)`，空间 `O(n)`；大规模全部出局顺序需要更高效的顺序统计结构。

## 只求最后存活者

用从 0 开始的编号定义：

$$
f(1)=0,\qquad f(k)=(f(k-1)+m)\bmod k.
$$

```cpp
// 返回原始 1 基编号；n >= 1、m >= 1。
int josephusSurvivor(int n, long long m) {
    long long pos = 0;
    for (long long k = 2; k <= n; ++k)
        pos = (pos + m % k) % k;
    return static_cast<int>(pos + 1);
}
```

此递推不需要保存或删除人员，时间 `O(n)`，空间 `O(1)`。最后存活者递推使用 `+m`，出局位置模拟使用 `+m-1`，不要混用。[原位置公式截图](../assets/约瑟夫环/位置公式.png)仅适合作为当前下标公式参考。
