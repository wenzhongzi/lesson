# 最长回文子串

回文串正读和倒读相同。**子串连续，子序列可以不连续**；本章求最长连续回文子串。

## 中心扩展

- 奇数长度：以 `(i,i)` 为中心，例如 `aba`。
- 偶数长度：以 `(i,i+1)` 为中心，例如 `abba`。
- 扩展失败时，`left/right` 指向回文外侧，真正区间是 `[left+1,right-1]`，长度 `right-left-1`。

```cpp
// 需要 <string>；字符串长度需可用 int 表示。
string longestPalindrome(const string& s) {
    int n = static_cast<int>(s.size()), bestStart = 0, bestLen = 0;
    auto expand = [&](int left, int right) {
        while (left >= 0 && right < n && s[left] == s[right]) {
            --left;
            ++right;
        }
        int len = right - left - 1;
        if (len > bestLen) {
            bestLen = len;
            bestStart = left + 1;
        }
    };
    for (int i = 0; i < n; ++i) {
        expand(i, i);
        expand(i, i + 1);
    }
    return s.substr(bestStart, bestLen);
}
```

时间 `O(n²)`，辅助空间 `O(1)`，不计返回字符串。空串返回空串；`"babad"` 返回 `"bab"`；`"cbbd"` 返回 `"bb"`。
