# 背包与硬币问题

动态规划先定义状态含义，再写转移、初始化和遍历顺序。原笔记重复的二维 0-1 背包代码已合并，并与一维优化写法对照。

## 背包模板对照

| 问题 | 每种物品使用次数 | 一维容量遍历 |
| --- | --- | --- |
| 0-1 背包 | 至多一次 | 从大到小 |
| 完全背包 | 任意次 | 从小到大 |

下列价值模板中，`dp[j]` 表示**总重量不超过 `j` 的最大价值**，允许不选任何物品，所以所有容量初始化为 0。要求物品重量为正，容量非负，总价值可用 `long long` 表示。

## 0-1 背包：二维状态

`dp[i][j]`：只使用前 `i` 个物品，容量不超过 `j` 的最大价值。

$$
dp[i][j]=
\begin{cases}
dp[i-1][j], & j<w_i,\\
\max(dp[i-1][j],dp[i-1][j-w_i]+v_i), & j\ge w_i.
\end{cases}
$$

```cpp
// 需要 <algorithm>、<vector>；w、value 等长，下标从 0 开始。
long long knapsack01Table(const vector<int>& w,
                          const vector<long long>& value, int W) {
    int n = static_cast<int>(w.size());
    vector<vector<long long>> dp(n + 1, vector<long long>(W + 1, 0));
    for (int i = 1; i <= n; ++i) {
        for (int j = 0; j <= W; ++j) {
            dp[i][j] = dp[i - 1][j];
            if (j >= w[i - 1])
                dp[i][j] = max(dp[i][j], dp[i - 1][j - w[i - 1]] + value[i - 1]);
        }
    }
    return dp[n][W];
}
```

时间 `O(nW)`，空间 `O(nW)`。

## 0-1 背包：一维优化

```cpp
// 需要 <algorithm>、<vector>。
long long knapsack01(const vector<int>& w,
                     const vector<long long>& value, int W) {
    vector<long long> dp(W + 1, 0);
    for (int i = 0; i < static_cast<int>(w.size()); ++i)
        for (int j = W; j >= w[i]; --j)
            dp[j] = max(dp[j], dp[j - w[i]] + value[i]);
    return dp[W];
}
```

倒序使 `dp[j-w[i]]` 仍来自上一轮，避免同一物品被重复使用。时间 `O(nW)`，空间 `O(W)`。

## 完全背包：最大价值

```cpp
// 需要 <algorithm>、<vector>。
long long completeKnapsack(const vector<int>& w,
                           const vector<long long>& value, int W) {
    vector<long long> dp(W + 1, 0);
    for (int i = 0; i < static_cast<int>(w.size()); ++i)
        for (int j = w[i]; j <= W; ++j)
            dp[j] = max(dp[j], dp[j - w[i]] + value[i]);
    return dp[W];
}
```

正序允许读取本轮已经更新过的状态，所以同一物品可重复使用。零重量正价值物品会使完全背包最优值无界，不能直接套用。

## 完全背包：最少硬币数

每种面额可无限使用，求**恰好**凑出目标金额所需的最少硬币数。

```cpp
// 需要 <algorithm>、<limits>、<vector>；面额正整数，target >= 0。
// target 及可行答案必须小于 INF，无解返回 -1。
int minCoins(const vector<int>& coins, int target) {
    const int INF = numeric_limits<int>::max() / 2;
    vector<int> dp(target + 1, INF);
    dp[0] = 0;
    for (int coin : coins)
        for (int money = coin; money <= target; ++money)
            if (dp[money - coin] != INF)
                dp[money] = min(dp[money], dp[money - coin] + 1);
    return dp[target] == INF ? -1 : dp[target];
}
```

这里不是“容量不超过”的问题，除 `dp[0]` 外都应初始化为不可达。若要求恰好装满时的最大价值，应使用负无穷表示不可达，并只从可达状态转移。

## 硬币计数：组合与排列

`dp[money]` 为恰好凑出该金额的方法数，`dp[0]=1`，表示空方案。假设面额为互不相同的正整数、金额非负，模数满足 `1 <= MOD <= 2×10^9`（包含常用的 `1000000007`）。

```cpp
// 需要 <vector>；组合：先枚举币种，再正序枚举金额。
long long coinCombinations(const vector<int>& coins, int target, long long MOD) {
    vector<long long> dp(target + 1, 0);
    dp[0] = 1 % MOD;
    for (int coin : coins)
        for (int money = coin; money <= target; ++money)
            dp[money] = (dp[money] + dp[money - coin]) % MOD;
    return dp[target];
}
```

```cpp
// 需要 <vector>；排列：先枚举金额，再枚举最后一枚硬币。
long long coinPermutations(const vector<int>& coins, int target, long long MOD) {
    vector<long long> dp(target + 1, 0);
    dp[0] = 1 % MOD;
    for (int money = 1; money <= target; ++money)
        for (int coin : coins)
            if (money >= coin)
                dp[money] = (dp[money] + dp[money - coin]) % MOD;
    return dp[target];
}
```

例：面额 `[1,2]`，目标 3。组合有 `{1,1,1}`、`{1,2}`，共 2 种；排列有 `1+1+1`、`1+2`、`2+1`，共 3 种。重复面额会造成重复计数，应先去重。

上述硬币算法时间 `O(币种数 × 金额)`，空间 `O(金额)`。[原始 DP 思路图](../assets/动态规划/动态规划步骤.png)。
