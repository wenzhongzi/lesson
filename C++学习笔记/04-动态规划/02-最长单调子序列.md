# 最长单调子序列

子序列允许跳过元素，但必须保持原位置先后顺序。严格递增要求后一个值更大；非严格递增允许相等。

## 朴素 DP

`dp[i]` 表示**以 `a[i]` 结尾**的最长严格递增子序列长度。

$$
dp[i]=\max\bigl(1,\ \max_{j<i,\ a[j]<a[i]}(dp[j]+1)\bigr).
$$

```cpp
// 需要 <algorithm>、<vector>。
int lisQuadratic(const vector<int>& a) {
    int n = static_cast<int>(a.size()), ans = 0;
    vector<int> dp(n, 1);
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < i; ++j)
            if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
        ans = max(ans, dp[i]);
    }
    return ans;
}
```

时间 `O(n²)`，空间 `O(n)`。

## 二分优化

`tails[k]` 表示已扫描元素中，长度为 `k+1` 的严格递增子序列的最小可能结尾。结尾越小，越容易接上后续元素。

```cpp
// 需要 <algorithm>、<vector>。
int lisLength(const vector<int>& a) {
    vector<int> tails;
    for (int x : a) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    return static_cast<int>(tails.size());
}
```

升序下 `lower_bound` 找第一个 `>= x` 的位置，相等值替换而不增长，所以得到严格递增长度；非严格递增改用 `upper_bound`，找第一个 `> x` 的位置。[标准库接口说明](https://learn.microsoft.com/en-us/cpp/standard-library/algorithm?view=msvc-170)。

时间 `O(n log n)`，空间 `O(n)`。`tails` 可求长度，但其最终内容不一定是原数组中的一条实际子序列。若要恢复方案，需额外记录前驱与原位置。

## 四种关系

| 目标 | 查找接口 | 比较器 |
| --- | --- | --- |
| 严格递增 | `lower_bound` | 默认升序 |
| 非严格递增 | `upper_bound` | 默认升序 |
| 严格递减 | `lower_bound` | `greater<int>()` |
| 非严格递减 | `upper_bound` | `greater<int>()` |

使用 `greater<int>()` 需 `<functional>`，且维护的 `tails` 顺序也应为降序。例如严格递减：

```cpp
// 需要 <algorithm>、<functional>、<vector>。
int ldsLength(const vector<int>& a) {
    vector<int> tails;
    for (int x : a) {
        auto it = lower_bound(tails.begin(), tails.end(), x, greater<int>());
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    return static_cast<int>(tails.size());
}
```

## 原示例修正

对 `[6,4,4,3]`：

| 类型 | 长度 | 一个合法示例 |
| --- | --- | --- |
| 严格递增 | 1 | `[6]` |
| 非严格递增 | 2 | `[4,4]` |
| 严格递减 | 3 | `[6,4,3]` |
| 非严格递减 | 4 | `[6,4,4,3]` |

原文把 `[4,6]` 等当作原序列的递增子序列，违反了位置顺序，相关答案已经修正。

## 最少划分问题

将一个序列的所有元素划分为若干条**非严格递减（不上升）子序列**，每条保持原下标顺序，最少条数等于最长**严格递增**子序列长度。

严格递增子序列的任意两个元素不能放进同一条不上升子序列，因此 LIS 长度给出下界；按贪心方式把每个新元素放到能接住它的、结尾最小的已有序列，不能接时新建，可达到这个下界。不要把“非严格递减”与“严格递减”的划分结论混用。
