# 最大连续乘积

求非空数组中乘积最大的**非空连续子数组**。与最大连续和不同，负数会让大小关系反转，所以同时维护两个状态。

- `maxEnd`：以当前位置结尾的最大乘积。
- `minEnd`：以当前位置结尾的最小乘积。

当前位置为 `x` 时：

$$
\begin{aligned}
newMax &= \max(x,oldMax\cdot x,oldMin\cdot x),\\
newMin &= \min(x,oldMax\cdot x,oldMin\cdot x).
\end{aligned}
$$

```cpp
// 需要 <algorithm>、<vector>；a 非空，所有候选乘积均在 long long 范围内。
long long maxProduct(const vector<long long>& a) {
    long long maxEnd = a[0], minEnd = a[0], ans = a[0];
    for (int i = 1; i < static_cast<int>(a.size()); ++i) {
        long long x = a[i], oldMax = maxEnd, oldMin = minEnd;
        maxEnd = max({x, oldMax * x, oldMin * x});
        minEnd = min({x, oldMax * x, oldMin * x});
        ans = max(ans, maxEnd);
    }
    return ans;
}
```

例：`[2,3,-2,4]` 的答案为 6；`[-2,3,-4]` 的答案为 24；`[-2,0,-1]` 的答案为 0。

必须用上一轮的两个值同时转移，不能先更新 `maxEnd` 再用它计算 `minEnd`。时间 `O(n)`，辅助空间 `O(1)`；只求最终答案时不用维护两张完整数组。[原始状态转移图](../assets/动态规划/最大连续乘积.jpg)。
