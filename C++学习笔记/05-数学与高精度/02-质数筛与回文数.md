# 质数筛与回文数

## 埃氏筛

生成 `[0,n]` 内的质数标记。0、1 不是质数；每个质数从它的平方开始标记倍数，因为更小倍数已由更小质因数处理。

```cpp
// 需要 <vector>；要求 n >= 0，n+1 可表示且标记数组能放入内存。
vector<bool> sieve(int n) {
    vector<bool> prime(n + 1, true);
    prime[0] = false;
    if (n >= 1) prime[1] = false;
    for (int i = 2; i <= n / i; ++i) {
        if (!prime[i]) continue;
        for (long long j = 1LL * i * i; j <= n; j += i)
            prime[static_cast<size_t>(j)] = false;
    }
    return prime;
}
```

用 `i <= n/i` 和 `1LL*i*i` 避免 `int` 的平方溢出。时间 `O(n log log n)`，标记数量 `O(n)`。原文标题 `ais` 按其代码内容整理为埃氏筛。

## 回文数与质数

十进制偶数位回文数都能被 11 整除，因为奇数位数字和与偶数位数字和相同，交错和为 0。因此，**偶数位回文质数只有 11**；大于 11 的偶数位回文数可直接排除。

例如 1221、1331 都是 11 的倍数。此性质针对标准十进制表示，不包含人为补前导零的字符串。

```cpp
// 需要 <algorithm>、<string>；判断非负整数是否回文。
bool isPalindromeNumber(long long x) {
    if (x < 0) return false;
    string s = to_string(x), reversed = s;
    reverse(reversed.begin(), reversed.end());
    return s == reversed;
}
```

筛选回文质数时，可以先筛出质数再判断回文；区间很大时，考虑先构造候选回文数，再检验质数。筛表只能用于其已预处理的数值范围。
