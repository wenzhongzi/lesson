# 卡特兰数

统一原文 `katelan` 为“卡特兰数（Catalan numbers）”。

## 定义与公式

$$
C_0=1,\qquad C_n=\sum_{i=0}^{n-1}C_iC_{n-1-i}.
$$

$$
C_n=\frac{1}{n+1}\binom{2n}{n},\qquad
C_n=C_{n-1}\frac{4n-2}{n+1}\quad(n\ge1).
$$

前几项为 `1,1,2,5,14,42,132,429`。递推与组合公式可参考 [Richard P. Stanley 的 MIT 讲义](https://math.mit.edu/~rstan/transparencies/tsuda.pdf)。

## 常见模型

| 模型 | `n` 的含义 | 条件 |
| --- | --- | --- |
| 合法括号串 | 括号对数 | 左右括号各 n 个，任何前缀中左括号不少于右括号 |
| 合法出栈顺序 | 入栈元素数 | 入栈次序固定，元素互不相同 |
| 有序二叉树结构 | 节点数 | 左右孩子位置有区别，不给节点任意增加标签 |
| 凸多边形三角划分 | 边数减 2 | 凸 n+2 边形，用不相交对角线划分 |
| 不越对角线路径 | 向右 / 向上步数各 n | 从 (0,0) 到 (n,n)，始终满足 y <= x |
| 排队找零 | 两种付款各 n 人 | 商品 5 元，付 5 元和 10 元各 n 人，初始无零钱；仅计付款类型序列 |

以上模型都需检查具体条件。仅看到“前缀不失衡”不足以直接判定卡特兰数：两类操作总数是否相等、是否带标签、是否还有额外约束，都可能改变答案。上述基本模型也见 [MIT 卡特兰数讲义](https://math.mit.edu/~rstan/transparencies/tsuda.pdf)。

## 递推模板

```cpp
// 需要 <vector>；仅用于 0 <= n <= 35，C_35 仍在有符号 long long 范围内。
long long catalan(int n) {
    vector<long long> c(n + 1, 0);
    c[0] = 1;
    for (int i = 1; i <= n; ++i)
        for (int j = 0; j < i; ++j)
            c[i] += c[j] * c[i - j - 1];
    return c[n];
}
```

时间 `O(n²)`，空间 `O(n)`。结果更大时用高精度；若题目要求取模，可在每次乘加时取模，并保证乘法不溢出。

乘法递推应先乘后除，不能先计算整数 `(4n-2)/(n+1)`；即使最终结果在范围内，中间乘积也可能超范围。模意义下除以 `n+1` 不能当普通整数除法，只有在逆元存在时才能用逆元，否则使用不含除法的递推或其他方法。
