# 高精度四则运算

整数超过内置类型范围时，用十进制字符串保存，每位分别计算。原笔记两份重复的乘法实现已合并，函数统一命名，修复幂函数调用未定义 `mul` 的问题。

## 使用约定

- 所有输入是**非空、只含 `0..9` 的非负整数字符串**，允许前导零。
- 输出去掉前导零，零统一表示为 `"0"`。
- 减法允许返回带 `-` 的结果，但其余函数不接受带符号输入；要继续计算负数，需要另行实现符号层。
- 所有函数共用以下辅助函数，需 `<algorithm>`、`<stdexcept>`、`<string>`、`<utility>`、`<vector>`。数字长度及其总长度应能用 `int` 表示并放入内存。

## 辅助函数

```cpp
string normalize(const string& s) {
    auto p = s.find_first_not_of('0');
    return p == string::npos ? "0" : s.substr(p);
}

int compareBig(string a, string b) {
    a = normalize(a);
    b = normalize(b);
    if (a.size() != b.size()) return a.size() > b.size() ? 1 : -1;
    if (a == b) return 0;
    return a > b ? 1 : -1;
}
```

长度相同时字典序即数值顺序；长度不同时先比较长度。

## 加法：逐位相加与进位

```cpp
string addBig(string a, string b) {
    a = normalize(a);
    b = normalize(b);
    int i = static_cast<int>(a.size()) - 1;
    int j = static_cast<int>(b.size()) - 1;
    int carry = 0;
    string result;
    while (i >= 0 || j >= 0 || carry) {
        int sum = carry;
        if (i >= 0) sum += a[i--] - '0';
        if (j >= 0) sum += b[j--] - '0';
        result.push_back(static_cast<char>('0' + sum % 10));
        carry = sum / 10;
    }
    reverse(result.begin(), result.end());
    return result;
}
```

从个位开始，把结果倒序保存，最后反转。`999 + 1 = 1000`。时间 `O(max(A,B))`，`A/B` 为输入位数。

## 减法：逐位相减与借位

```cpp
string subtractBig(string a, string b) {
    a = normalize(a);
    b = normalize(b);
    if (compareBig(a, b) < 0) return "-" + subtractBig(b, a);
    int i = static_cast<int>(a.size()) - 1;
    int j = static_cast<int>(b.size()) - 1;
    int borrow = 0;
    string result;
    while (i >= 0) {
        int digit = a[i--] - '0' - borrow;
        if (j >= 0) digit -= b[j--] - '0';
        if (digit < 0) {
            digit += 10;
            borrow = 1;
        } else {
            borrow = 0;
        }
        result.push_back(static_cast<char>('0' + digit));
    }
    reverse(result.begin(), result.end());
    return normalize(result);
}
```

`1000 - 1 = 999`，`3 - 5 = -2`。时间 `O(max(A,B))`。

## 乘法：逐位相乘与及时进位

低位放在前面，原理是 `result[i+j] += a[i]*b[j]`。下面每次乘加都立即进位，避免先把过多乘积累计在一个 `int` 中。

```cpp
string multiplyBig(string a, string b) {
    a = normalize(a);
    b = normalize(b);
    if (a == "0" || b == "0") return "0";
    reverse(a.begin(), a.end());
    reverse(b.begin(), b.end());
    int m = static_cast<int>(a.size()), n = static_cast<int>(b.size());
    vector<int> digit(m + n, 0);
    for (int i = 0; i < m; ++i) {
        int carry = 0;
        for (int j = 0; j < n; ++j) {
            int sum = digit[i + j] + (a[i] - '0') * (b[j] - '0') + carry;
            digit[i + j] = sum % 10;
            carry = sum / 10;
        }
        digit[i + n] = carry;
    }
    while (digit.size() > 1 && digit.back() == 0) digit.pop_back();
    string result;
    for (int i = static_cast<int>(digit.size()) - 1; i >= 0; --i)
        result.push_back(static_cast<char>('0' + digit[i]));
    return result;
}
```

`12 × 34 = 408`。时间 `O(AB)`，空间 `O(A+B)`。

## 除法：长除法，返回商和余数

从高位到低位读入被除数，每次将一位追加到当前余数中，计算这一位商。进入下一位前余数小于除数，所以每一位商最多是 9。

```cpp
pair<string, string> divideBig(string a, string b) {
    a = normalize(a);
    b = normalize(b);
    if (b == "0") throw invalid_argument("division by zero");
    string quotient, remainder = "0";
    for (char c : a) {
        remainder = normalize(remainder + c);
        int digit = 0;
        while (compareBig(remainder, b) >= 0) {
            remainder = subtractBig(remainder, b);
            ++digit;
        }
        quotient.push_back(static_cast<char>('0' + digit));
    }
    return {normalize(quotient), normalize(remainder)};
}
```

`123 ÷ 10` 返回 `{"12","3"}`；`5 ÷ 10` 返回 `{"0","5"}`。除数 `"0000"` 规范化后也是 0，必须拒绝。

朴素实现时间可用 `O(A(A+B))` 上界估计，适合学习与中小位数；反复减法每位最多 9 次，而不是按商的整个数值逐次相减。

## 大数对普通整数取模

逐位更新 `remainder = (remainder*10 + digit) % mod`。

```cpp
// 要求 1 <= mod <= 2'000'000'000，保证中间计算不溢出。
long long bigModulo(const string& s, long long mod) {
    long long remainder = 0;
    for (char c : s) remainder = (remainder * 10 + (c - '0')) % mod;
    return remainder;
}
```

余数是数字类型，不是字符串。时间 `O(A)`，空间 `O(1)`。

## 高精度幂

```cpp
// 要求 exponent >= 0；结果必须能放入内存。
string powerBig(string a, int exponent) {
    a = normalize(a);
    string result = "1";
    while (exponent > 0) {
        if (exponent & 1) result = multiplyBig(result, a);
        exponent >>= 1;
        if (exponent > 0) a = multiplyBig(a, a);
    }
    return result;
}
```

乘法调用次数为 `O(log exponent)`，每次高精度乘法的成本随位数增长，不能把总时间简单写成 `O(log exponent)`。指数为 0 时按空乘积约定返回 `"1"`。

以上代码可按顺序组合使用；示例：

```cpp
// 需要 <iostream>；依赖上述函数；放在 main 内。
cout << addBig("00099", "1") << '\n';  // 100
cout << subtractBig("3", "5") << '\n'; // -2
cout << multiplyBig("12", "34") << '\n'; // 408
auto [q, r] = divideBig("123", "10");
cout << q << ' ' << r << '\n';          // 12 3
cout << powerBig("2", 10) << '\n';      // 1024
```
