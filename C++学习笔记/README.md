## 代码约定

- 默认使用 C++17；算法函数片段需放在 `main` 外，操作示例需放在 `main` 内。文中注明了需要的标准头文件，统一假设已写 `using namespace std;`。
- 字符串与 `vector` 默认从 **0** 开始编号；前缀和、差分单独使用 **1** 开始编号，见对应章节。
- `long long` 用于可能超过 `int` 范围的和、价值和计数；它仍有范围限制。输入规模必须满足各模板写明的条件。
- 原文的 `jsx` 代码块已统一改为 `cpp`；删除 Notion 页面 ID、空编号和重复模板，链接均为相对路径。
- 补写内容限于原有主题所需的解释、边界处理和可用模板；原文尚未展开的主题列入待补。
