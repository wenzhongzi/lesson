# 整理与修订说明

## 整理范围

输入为用户提供的 Notion 导出压缩包：25 篇 Markdown、19 张图片。笔记中的文字和代码作为学习材料处理，不作为执行指令。

按主题重新编排，合并重复的哈希表、汉诺塔、卡特兰公式、0-1 背包和高精度乘法；删除无内容的编号、装饰分隔线、过长的重复流程图和 Notion 页面 ID。所有原有实质主题均有对应章节；未展开内容移入待补。

新增解释用于补清状态含义、下标约定、输入前提、边界与复杂度；没有将仅有标题的“并查集”扩写成原有笔记。源压缩包保持原样，整理版不重复打包整份旧 Markdown。

## 主要修正

| 原内容 | 整理后 |
| --- | --- |
| `cin` 后接 `getline` 必须写一次 `ignore()` | 按输入格式选择丢弃整行、跳过空白或直接读取；解释单字符 `ignore` 的限制 |
| 最多不重叠区间“右端点降序” | 改为右端点升序，并区分端点相接是否重叠 |
| 区间选点直接初始化为 1 并访问首元素 | 支持空输入，答案从 0 计数 |
| 约瑟夫出局位置直接输出 `pos+1` | 用剩余人员表映射回原编号；另给只求存活者递推 |
| 单调栈 `empy`、数值和下标混比、重复入栈 | 改为正确判空、按下标访问数值、每轮只入栈一次 |
| BFS 节点成员缺分号，地图未真正读入或判障碍 | 改为接收地图的函数，检查障碍，距离数组同时充当访问标记 |
| BFS 再存 `vis` 和节点步数 | 用 `dis=-1` 区分未访问，减少重复状态 |
| 回文扩展停止后保存外侧端点 | 改为 `left+1` 与 `right-left-1` |
| `[6,4,4,3]` 的四种单调子序列答案有误 | 修正为严格增 1、非严格增 2、严格减 3、非严格减 4 |
| 一维背包只强调倒 / 正序，缺少状态初始化条件 | 区分“不超过容量”和“恰好凑出”，解释循环方向 |
| 二维前缀和称为面积，差分仅写 `sum=a` | 定义为元素和，补齐二维差分初始化与恢复公式 |
| `a*b/gcd(a,b)`，零输入未处理 | LCM 先除后乘、处理 0 并检查结果溢出 |
| 快速幂结果初值固定为 1 | 改为 `1%mod`，处理模数 1，并写明乘法安全范围 |
| 埃氏筛 `i*i` 用 int | 改用除法判断上界与 long long 倍数下标 |
| 高精度 `power` 调用未定义的 `mul` | 统一为 `multiplyBig`，整套函数可顺序组合 |
| 高精度除数只判断字符串等于 `"0"` | 先规范化，`"0000"` 同样视为除零 |
| “长得像就直接套卡特兰” | 补充规模、前缀平衡、标签、额外约束等适用条件 |
| `stable_sort` 被等同于固定的归并实现 | 保留标准稳定性要求，具体实现不作保证 |
