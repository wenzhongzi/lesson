# 易错点速查

| 主题 | 核心提醒 | 详细笔记 |
| --- | --- | --- |
| 等价无穷小 | 相减可能抵消低阶项，不能只替换一阶近似 | [极限](01-一元微积分/01-极限与等价无穷小.md) |
| 不定积分 | 最后带 $C$；对数注意绝对值与定义区间 | [积分公式](01-一元微积分/02-常用积分公式.md) |
| 换元 | 变量、微分、定积分上下限都要同步修改 | [换元](01-一元微积分/03-换元积分.md) |
| 三角幂次 | 奇次留导数因子，偶次考虑降幂；$\sqrt{x^{2}}=\lvert x\rvert$ | [三角积分](01-一元微积分/04-三角函数积分.md) |
| 分部积分 | 循环积分回代时不要漏项；积分常数最后统一合并 | [分部积分](01-一元微积分/05-分部积分与递推.md) |
| 有理分式 | 重复因子要列出每个幂次；$n=1$ 与 $n\ge 2$ 分开 | [有理积分](01-一元微积分/06-有理分式积分.md) |
| 定积分奇偶性 | 普通可积前提下才能用；奇点上的反常积分需另判 | [定积分](01-一元微积分/07-定积分技巧.md) |
| 变限积分 | 参数也在被积函数内时，不能只对上限求导 | [变限积分](01-一元微积分/08-变限积分.md) |
| 二元极限 | 多条路径相同不足以证明存在；两条不同足以否定 | [二元极限](02-多元微分/01-二元极限与连续.md) |
| 偏导与可微 | 偏导存在不保证连续或可微；偏导连续是充分条件 | [全微分](02-多元微分/02-偏导数与全微分.md) |
| 混合偏导 | 交换次序需要条件，不能只看两者都存在 | [偏导数](02-多元微分/02-偏导数与全微分.md) |
| 链式法则 | 中间变量的每条依赖路径都要计入 | [复合函数](02-多元微分/03-复合函数与隐函数.md) |
| 隐函数 | 分母偏导不为零，才能直接用分式公式 | [隐函数](02-多元微分/03-复合函数与隐函数.md) |
| 方向导数 | 先把方向单位化；不可微时不能直接用梯度公式 | [方向与梯度](02-多元微分/04-方向导数与梯度.md) |
| 极值与最值 | 驻点只是候选；闭域最值还要检查边界与不可微点 | [极值](02-多元微分/05-极值与最值.md) |
| 向量 | 两曲面法向量叉积是交线切向量 | [空间几何](02-多元微分/06-空间曲线与曲面.md) |
| 积分换序 | 先画区域，新上下限必须表达同一个区域 | [二重积分](03-重积分/01-二重积分与换序.md) |
| 积分分离 | 被积函数是乘积还不够，通常还要求矩形区域 | [二重积分](03-重积分/01-二重积分与换序.md) |
| 极坐标 | 面积元带 $r$；球坐标体积元带 $r^{2}\sin \varphi$ | [坐标变换](03-重积分/02-坐标变换与对称性.md)、[三重积分](03-重积分/03-三重积分.md) |
| 雅可比 | 无向重积分面积元取绝对值；有向积分另管方向 | [坐标变换](03-重积分/02-坐标变换与对称性.md) |
| 质心与惯量 | 质量加权必须带密度；$I_{x}$ 用到 x 轴的距离平方 | [应用](03-重积分/04-重积分应用.md) |
| 第一 / 第二类 | 第一类不随方向改变，第二类反向变号 | [曲线](04-曲线与曲面积分/01-曲线积分与格林公式.md)、[曲面](04-曲线与曲面积分/03-曲面积分.md) |
| 格林 | 外边界逆时针、内边界顺时针；内部奇点不可忽略 | [格林公式](04-曲线与曲面积分/01-曲线积分与格林公式.md) |
| 路径无关 | 用交叉偏导判别时检查开单连通及连续偏导条件 | [全微分方程](04-曲线与曲面积分/02-路径无关与全微分方程.md) |
| 高斯 / 斯托克斯 | 高斯用闭曲面外侧；斯托克斯用右手定向 | [积分定理](04-曲线与曲面积分/04-高斯与斯托克斯公式.md) |
| 数项级数 | 通项趋零只是必要条件；比值 / 根值为 1 无法判断 | [数项级数](05-无穷级数/01-数项级数.md) |
| 级数收敛类型 | 绝对值级数发散，仍可能条件收敛 | [数项级数](05-无穷级数/01-数项级数.md) |
| 幂级数半径 | 不等于完整收敛域；端点逐一代入原式 | [幂级数](05-无穷级数/02-幂级数与收敛域.md) |
| 幂级数运算 | 逐项求导 / 积分保半径，但端点需重查 | [幂级数](05-无穷级数/02-幂级数与收敛域.md) |
| 求和闭式 | 除以 $x$ 后补回中心；闭式定义域不能替代级数收敛域 | [求和](05-无穷级数/03-幂级数展开与求和.md) |
| 一致收敛 | 逐点收敛不自动保证和函数连续或逐项求导 | [收敛条件](05-无穷级数/02-幂级数与收敛域.md) |
| 傅里叶 | 周期 $2\pi$ 的系数带 $1/\pi$；跳跃点取左右平均 | [傅里叶](05-无穷级数/04-傅里叶级数.md) |
| 半区间展开 | 奇 / 偶延拓决定正弦 / 余弦；端点不一定等于原值 | [傅里叶](05-无穷级数/04-傅里叶级数.md) |
