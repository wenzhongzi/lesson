## 阅读约定

- 全部公式与数学符号一律用 LaTeX：行内用 `$...$`，独立公式用 `$$...$$`（单独占行，前后空行），可在 GitHub 或支持数学公式的 Markdown 阅读器中直接渲染。表格、索引与说明文字中的公式同样如此。
- 不使用 Unicode 数学字符（如 `≤`、`∞`、`∫`、`x²`）。函数名写作 `\sin x`、`\ln x`、`\arctan x`，微分写作 `\,dx`，绝对值写作 `\lvert x\rvert`。
- 不定积分结果统一带常数 $C$；公式在被积函数有定义、所写运算合法的区间上使用。
- 根式积分默认参数 $a>0$；方向导数使用单位方向向量；第一类积分用无向长度 / 面积元，第二类积分注明方向。
- 同一主题只保留一份主要说明，跨主题内容用链接连接。原稿中的重复截图、空白空间不进入正文，但完整原页图仍可回查。
- 正文补齐的例题计算是整理时推导的结果，并非声称原稿已有完整解答；相关位置均注明“补齐”。
