## 阅读约定

- 数学公式采用 LaTeX，适合在 GitHub 或支持数学公式的 Markdown 阅读器中查看。
- 线性规划主约定为最大化 $z=c^Tx$，检验数 $\sigma_{j}=c_{j}-c_{B}^TB^{-1}a_{j}$；当前基可行且所有检验数非正时最优。运输最小化问题另用 $\Delta_{ij}=c_{ij}-u_{i}-v_{j}$，最优条件为非负。
- 排队指标统一为 $L_{s},W_{s}$ 表示系统内人数与停留时间，$L_{q},W_{q}$ 表示队列人数与等待时间；$\lambda_{e}$ 表示实际进入系统的到达率。
- 库存模型用 $R$ 表示需求率、$P$ 表示生产率、$Q$ 表示批量、$T=\frac{Q}{R}$ 表示周期，避免原复习页混用批量与时间。
- 正文中标为“补齐”“整理补充”的计算是根据原数据重新推导的内容；不表示原稿已有完整答案。
